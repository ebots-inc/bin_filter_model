    Prepare a new bin setup

    New setup collects all selected bins together. After empty captures, place exactly one resistor in each bin at the same named location: center, each of the four walls, then the indicated corner. Each location has three arrangements; rotate or reposition each resistor between arrangements. Finally collect three normal and three full arrangements, using your usual production fill amounts without an exact count.

    This scene has an interrupted capture. Ready will preserve that attempt and retake the whole scene. Prepare the pictured arrangement again.

    Follow the current stage's instructions for every bin. Leave all parts unchanged while exposures are captured. Before the next arrangement, rotate or reposition the instructed parts, then click Ready. Each arrangement gets its own exposure sweep.

    Train and validate

    Fit the empty-bin geometry and camera corrections, then replay the saved empty, resistor and filled scenes through the production detector. The model is saved as JSON metadata and binary numerical arrays.

    Use this model requires passed physical validation and an available Perception reload service. It verifies the loaded model identity and restores the previous configuration if activation fails.
