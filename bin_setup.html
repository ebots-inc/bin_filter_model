    Create a bin layout from the camera view

    1. Empty the bins and leave them in their normal mounted positions. Keep the arm out of view.
    2. Check the camera connection, then capture the empty scene.
    3. Draw one box just outside each whole bin’s outer edge. Include the entire flat rim on all four sides; keep neighbouring bins outside the box.
    4. Review the measured bowl and rim, give the layout a name, and save it.

    This saves a layout for a new collection. Your open session and its captures stay unchanged.

    This is a top-down depth view in the selected reference frame. Drag just outside the complete outer edge, including every side of the flat top rim. It does not need to trace the curved bowl edge.

    Start each bin name with a letter, such as left, right or resistors. Select Draw again to replace a box. Remove any box drawn on the wrong object.

    Check every bin before saving

    Check the entire outer rim on every side against the original picture. The cyan interior should cover the bowl, and orange should cover the visible flat rim all the way around. A box can pass the checks while cutting off part of the rim. Redraw if any part is missing or a neighbouring bin is included.

    2. Capture scenes — follow one instruction at a time

    Prepare a new bin setup

    New setup collects all selected bins together. After empty captures, place exactly one resistor in each bin at the same named location: center, toward each of the four sides, then the bottom-left diagonal. Each location has three arrangements; rotate or reposition each resistor between arrangements. Finally collect three normal and three full arrangements, using your usual production fill amounts without an exact count.

    This scene has an interrupted capture. Ready will preserve that attempt and retake the whole scene. Prepare the pictured arrangement again.

    Follow the current stage's instructions for every bin. Leave all parts unchanged while exposures are captured. Before the next arrangement, rotate or reposition the instructed parts, then click Ready. Each arrangement gets its own exposure sweep.

    3. Add a CAD reference (optional)

    Have the bin’s STL file? Upload it here. You can also skip this step and train using the captured bin surfaces.

    Upload the complete bin, including the flat top rim. Different bin shapes can use separate uploads. STL files do not declare units or which direction points upward: choose these below.

    Open a collection session to upload CAD. Complete the captures before previewing placement.

    4. Build and validate

    Fit the empty-bin geometry and camera corrections, then replay the saved empty, resistor and filled scenes through the production detector. Every build creates a separate candidate.

    Open a session to see CAD references commissioned for its scene, reference frame and bins.

    CAD guides the shape while empty-bin captures retain the physical bin’s measured deviations. Printed and CNC bins use the same validation checks; choosing CAD does not loosen detection thresholds.

    Use this model requires passed physical validation and an available Perception reload service. It verifies the loaded model identity and restores the previous configuration if activation fails.
